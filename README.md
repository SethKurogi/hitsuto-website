# Hitsuto Website

This is a static bilingual (English / Japanese) website for Hitsuto.

Files:
- index.html — website content
- styles.css — design and responsive layout
- script.js — language switch + mobile menu
- hitsuto-logo.png — supplied Hitsuto logo

## Preview locally
Double-click `index.html` to open it in a browser.

## Free hosting options
### GitHub Pages
1. Create a GitHub repository.
2. Upload all four files.
3. In Settings → Pages, publish from the main branch.
4. Add `hitsuto.com` as the custom domain.
5. Update GoDaddy DNS with the records GitHub provides.

### Cloudflare Pages
1. Create a Cloudflare account.
2. Create a Pages project and upload the website files.
3. Add `hitsuto.com` as a custom domain.
4. Follow Cloudflare's DNS instructions.

## Before launch
- Confirm `hello@hitsuto.com` is working.
- Review Japanese copy.
- Add legal business name / LLC information once formed, if desired.
- Add privacy policy if you later add analytics, forms, or tracking.
